# Amazon Sales Performance Dashboard

## 📊 Project Overview

This project analyzes Amazon retail sales data using Microsoft Power BI
to identify sales trends, profitability patterns, customer segment
performance, product category performance, and regional performance.

## 🛠️ Tools Used

- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Business Analysis

## 📌 Dashboard KPIs

- Total Sales: $2.30M
- Total Profit: $286.40K
- Total Quantity: 38K
- Total Shipment Cost: $87.03K

## 📈 Dashboard Analysis

The dashboard analyzes:

- Sales by Product Category
- Sales Trend Over Time
- Sales & Profit by Customer Segment
- Sales & Profit by Category and Sub-Category
- Average Discount by Sub-Category
- Sales by Region
- Profit by State
- Geographic Distribution

## 🔍 Key Insights

1. Technology generated the highest sales and profit.
2. Furniture generated high sales but relatively low profit.
3. West was the strongest-performing region.
4. Central had relatively high discounting and lower profitability.
5. Tables generated significant sales but resulted in a loss.

## 💡 Recommendations

- Review pricing and discount strategies for low-margin products.
- Investigate loss-making sub-categories such as Tables.
- Focus growth strategies on profitable Technology products.
- Review discounting practices in the Central region.
- Expand successful strategies from the West region.
